# NexusHR – Employee Management System

**Simplifying Employee Management Through Smart Digital Solutions.**

NexusHR is a modern Employee Management System designed to simplify and organize employee-related information through a clean, intuitive and responsive user interface.

The application aims to provide organizations with a centralized platform to manage employee records and access essential workforce information efficiently.

## 🚀 Features

- **Dashboard:** Overview of employee-related information.
- **Employee Management:** Add, view, update and manage employee records.
- **Employee Search:** Search and access employee information easily.
- **Department Management:** Organize employees by department.
- **Salary Management:** Manage and calculate employee salary details.
- **Responsive Design:** User-friendly interface across different screen sizes.
- **Navigation:** Structured sidebar navigation for accessing different modules.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/HARISRI_45/NexusHR.git
```

### 2. Navigate to the Project Directory

```bash
cd NexusHR
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the localhost URL displayed in your terminal.
